Controls how the individual scene files inside each movie folder are named.

Parts — Files are named Movie Name - pt1.ext, pt2.ext… Jellyfin recognises these as multi-part files and plays them back-to-back automatically.
Scenes — Files are named using the scene’s own title, e.g. Movie Name - Scene Title.ext. Jellyfin lists them as individually selectable sections; playback is not automatic.
